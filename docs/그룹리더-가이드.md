# 그룹리더 안내 (v2.0)

그룹리더는 학습그룹이나 도전그룹을 만들고, 모임을 열고, 출석을 받고, 그룹원이 목표까지 가도록 이끄는 사람입니다. 이 문서는 그룹리더에게 그대로 전해도 되도록 썼습니다. 회원 공간 주소는 `/app/#/groups`입니다.

---

## 1. 그룹리더가 되는 법

1. 회원 공간 **내 정보 → 그룹리더**에서 신청합니다. 이끌고 싶은 그룹 종류(학습·도전), 주제, 운영 계획, 관련 경험, 쓸 수 있는 시간을 적습니다.
2. 운영진이 정기모임 참석과 활동 기록을 함께 보고 5일 안에 결과를 알려 드립니다.
3. 승인되면 언제든 그룹을 만들 수 있습니다. 한 사람이 동시에 이끌 수 있는 그룹은 기본 2개입니다.

등급과는 관계없습니다. 챌린저(L1)도 신청할 수 있습니다.

## 2. 그룹 만들기

**그룹 → 그룹 만들기**에서 아래를 정합니다. **학습그룹 예시 / 도전그룹 예시** 버튼을 누르면 목표·주기·마일스톤이 미리 채워집니다.

| 항목 | 쓰는 요령 |
|---|---|
| 그룹 종류 | 학습그룹은 함께 공부하고 정리, 도전그룹은 하나의 프로젝트로 성과·수익에 도전 |
| 그룹 이름·한 줄 소개 | 목록 카드에 보입니다. 무엇을 하는 그룹인지 한 번에 알 수 있게 |
| 자세한 소개 | 어떤 사람과 하고 싶은지, 모임은 어떻게 진행하는지 |
| 그룹 목표 | 기간과 숫자를 함께. 예: "8주 안에 첫 유료 고객 3명" |
| 목표로 세는 숫자·목표 수치 | 매출·유료 고객·판매·사용자·콘텐츠·학습 과제 중 하나. 그룹원이 성과를 기록하면 진행률이 올라갑니다 |
| 기간·마일스톤 | 중간 점검할 지점 2~4개 |
| 모이는 주기·장소 | 예: 매주 화요일 21시 온라인 · 월 1회 오프라인 |
| 정원·참여 방식 | 리더가 승인하는 방식 또는 누구나 바로 참여 |
| 그룹 대화방 링크 | 그룹원에게만 보입니다 |
| 출석 규칙 | 아래 3장 참고 |

만들면 바로 그룹 목록에 올라가 모집이 시작됩니다. 그룹원이 모이면 **진행 시작**을 누릅니다. 다음 정기모임에서 그룹을 소개하면 함께할 사람을 찾기 쉽습니다.

## 3. 출석 규칙 정하기

출석 규칙은 그룹을 내보내기 위한 것이 아니라 끝까지 함께 가기 위한 약속입니다. 처음 모임에서 이 점을 꼭 이야기해 주세요. 그룹원은 규칙을 확인했다고 표시해야 참여 신청을 할 수 있습니다.

| 항목 | 기본값 | 뜻 |
|---|---|---|
| 최소 출석률 | 70% | 0이면 쓰지 않음. 공결은 계산에서 뺌 |
| 출석률 확인 시작 | 3번째 모임부터 | 처음 몇 번은 출석률로 경고하지 않음 |
| 지각 기준 | 10분 | 시작 후 이 시간이 지나 코드를 넣으면 지각 |
| 지각 환산 | 3번 = 결석 1번 | 0이면 환산하지 않음 |
| 연속 결석 경고 | 2번 | 연속 결석이 이 횟수의 배수가 될 때마다 경고 |
| 출석률 경고 | 켬 | 출석률이 기준 아래로 내려가는 순간 경고 |
| 퇴출 기준 | 경고 2번 | 0이면 퇴출 기준 없음 |
| 자동 퇴출 | 끔 | 끄면 기준에 닿았을 때 리더에게 알림만 가고, 리더가 사정을 듣고 결정 |
| 공결 | 인정, 최대 2번 | 모임 시작 전에 불참 사유를 남긴 경우 |
| 출석 코드 입력 | 시작 30분 전부터 | |

진행 중에도 **설정** 탭에서 바꿀 수 있지만, 바꿀 때는 그룹원에게 먼저 알려 주세요.

## 4. 모임과 출석

1. **모임·출석** 탭에서 일정을 잡습니다. 이름, 시작 시각(한국 시간), 온라인·오프라인, 진행 시간, 장소나 온라인 링크, 다룰 것, 준비할 것. '매주 반복'에 4를 넣으면 같은 요일·시간으로 5번이 한 번에 만들어집니다.
2. 그룹원은 모임 전에 참석·불참을 알립니다. 불참 사유를 남기면 공결로 인정될 수 있습니다.
3. 모임이 시작되면 모임 화면에서 **출석 받기**를 누릅니다. 4자리 코드가 크게 나옵니다.
   - 오프라인: 화면을 보여 줍니다.
   - 온라인: 대화창에 코드를 올리거나 **출석 링크 복사**로 링크를 보냅니다(링크를 누르면 코드가 미리 채워집니다).
4. 코드를 넣지 못한 사람은 **출석 체크** 목록에서 출석·지각·결석·공결을 직접 누릅니다.
5. 모임이 끝나면 **출석 마감**. 표시하지 않은 사람은 결석, 미리 사유를 남긴 사람은 공결이 됩니다. 마감하지 않으면 모임이 끝나고 12시간 뒤 자동으로 마감됩니다. 마감한 뒤에도 표시는 고칠 수 있습니다.
6. **모임 기록**에 나눈 이야기와 정한 것을 남겨 두면 빠진 사람도 따라올 수 있습니다.

부리더를 지정하면(그룹원 탭 → 부리더로) 모임 일정과 출석 관리를 나눠 맡을 수 있습니다.

## 5. 경고와 퇴출

- 출석을 마감하면 출석 규칙에 따라 경고가 자동으로 나갑니다. 한 모임에서 경고는 한 번만 나옵니다.
- 직접 경고할 수도 있습니다(그룹원 탭 → 경고, 사유는 본인에게 그대로 전달).
- 사정을 듣고 경고를 취소할 수 있습니다. 취소한 경고는 퇴출 기준 계산에서 빠집니다.
- 퇴출 기준에 닿으면 알림이 옵니다. 먼저 이야기를 나눠 보고, 경고를 취소하거나 **내보내기**를 결정합니다.
- 내보낸 그룹원은 운영진에게 이의를 신청할 수 있고, 나간 그룹원 목록에서 **다시 받기**로 복귀시킬 수 있습니다.

## 6. 기록·목표·성과

- **도전 기록**: 진행 기록, 학습 노트, 자료 공유, 회고를 남깁니다. 리더는 공지를 쓰고 위에 고정할 수 있습니다. "커뮤니티 그룹 소식에도 공유"를 체크하면 다른 그룹도 보고 응원·조언합니다.
- **목표·성과**: 마일스톤을 완료 처리하고, 그룹원이 성과(매출·고객·판매·사용자·콘텐츠·학습 과제)를 기록합니다. 매출은 증빙과 함께 기록하면 운영진이 확인하고, 확인되면 그룹원 모두에게 첫 매출 배지가 나갑니다. 증빙에서 계좌번호와 고객 개인정보는 가리도록 안내해 주세요.
- 수익을 나누는 방식은 마챌이 아직 정하지 않았습니다. 그룹 안에서 돈이 오가기 시작하면, 받거나 쓰기 전에 그룹원끼리 방식을 먼저 정하고 그룹 기록으로 남겨 주세요. 이견이 생기면 운영진에게 조정을 요청합니다.

## 7. 정기모임·성과발표회

- 정기모임에서 그룹을 소개하거나 발제를 하고 싶으면 **정기모임·일정**에서 발제를 신청합니다.
- 성과발표회는 그룹리더나 부리더가 그룹 단위로 **그룹 발표 신청**을 합니다. 목표, 한 일, 숫자, 배운 점을 10분 안에 나눕니다. 목표에 닿지 못했어도 발표합니다.

## 8. 그룹 마치기와 페이퍼

1. **그룹 종료**를 누르면 열려 있던 출석이 마감되고, 앞으로 잡힌 모임은 취소됩니다.
2. 출석 기준을 채운 그룹원(최소 출석률을 쓰지 않으면 마감한 모임에 한 번 이상 나온 사람)은 **그룹 완주** 배지를 받습니다. 그룹리더도 완주하면 그룹리더 완주 배지를 받습니다.
3. **페이퍼** 탭에서 프로젝트 페이퍼를 씁니다. **불러오기**를 누르면 성과 기록의 매출·고객 수, 모임 시간 × 인원, 완료한 마일스톤이 채워집니다. 매출이 없어도, 중간에 멈췄어도 씁니다.
4. 운영진에게 제출하면 5일 안에 검토합니다. 매출 유무·고객 수 구간·들인 시간은 항상 공개되고, 나머지 숫자는 가릴 수 있습니다.

## 9. 운영진이 돕는 일

그룹리더 워크숍과 운영 가이드, 정기모임에서의 그룹 소개, 세미나·워크숍, 오피스아워, 모임 장소 안내, 필요한 기술을 가진 회원 연결. 막히면 언제든 운영진에게 이야기해 주세요.
