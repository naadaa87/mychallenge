# 운영본부 콘솔 사용 안내 (v2.2)

운영본부는 **https://mychallenge.kr/admin** 에서 엽니다. 운영진·총괄관리자 계정으로 로그인하면 바로 현황이 열리고, 회원 공간에서는 위쪽 메뉴의 **운영본부**(휴대폰에서는 아래쪽 **운영** 탭)를 눌러도 옵니다. 회원 공간과 같은 계정을 쓰며, 예전 주소(`/app/#/admin/…`)로 들어와도 `/admin`으로 이어집니다. 운영진이 아닌 계정으로 들어오면 안내만 보입니다.

화면은 왼쪽 메뉴와 오른쪽 본문으로 나뉩니다. 휴대폰에서는 왼쪽 메뉴 대신 위쪽의 **☰ 메뉴** 버튼을 누르면 전체 메뉴가 열립니다. 어느 화면에서든 위쪽 검색창에 닉네임, 이름, 이메일, 그룹 이름을 넣으면 바로 찾아갑니다. Enter를 누르면 첫 결과로 이동합니다. 주소는 `/admin/#/users/12`처럼 메뉴 이름이 붙어 있어 그대로 공유할 수 있습니다.

v2.0부터 마챌은 **정기모임 → 학습그룹·도전그룹 → 기록·공유 → 성과발표회** 흐름으로 운영합니다. 수익 배분, 합의서, 정산, 지급 화면은 없어졌습니다. 운영 모델과 근거는 [운영모델-v2.md](운영모델-v2.md), 그룹리더에게 줄 안내는 [그룹리더-가이드.md](그룹리더-가이드.md)에 있습니다.

## 1. 권한: 운영진과 총괄관리자

| 할 수 있는 일 | 운영진 | 총괄관리자 |
|---|:---:|:---:|
| 받은 일 처리 (가입, 그룹리더 신청, 매출 확인, 발표 신청, 페이퍼, 승급, 이의·신고) | ✓ (담당 영역 안) | ✓ |
| 회원 등급·배지·상태 조정, 그룹리더 자격 주기·거두기, 임시 비밀번호 | ✓ (담당 영역 안) | ✓ |
| 그룹 중단·종료·재개, 그룹리더 교체, 퇴출된 그룹원 복귀 | ✓ (담당 영역 안) | ✓ |
| 단체 알림, 정기모임·일정·출석·발표, 단체카톡방, 커뮤니티 관리 | ✓ (담당 영역 안) | ✓ |
| 현황, 회원·그룹 조회, 통합 검색, 내부 메모, 감사 로그 보기 | ✓ | ✓ |
| 그룹·그룹원·모임·출석·성과·페이퍼·포인트 CSV | ✓ | ✓ |
| 총괄 현황, 보안·접속 기록, 로그인 강제 종료 | – | ✓ |
| 운영진 지정·해제, 담당 영역 정하기, 다른 운영진의 정보 변경 | – | ✓ |
| 사이트 운영(회원 신청 받기·닫기, 공지 띠), 규칙 설정 변경, 단체카톡방 설정 | – | ✓ |
| KPI 월 목표, 방문 통계 수집 켜기·끄기와 시작일 | – | ✓ |
| 회원·가입 신청·동의 기록 CSV, 전체 백업, 데이터 정리 | – | ✓ |

- 운영진은 모든 그룹에서 그룹리더와 같은 권한(모임 열기, 출석 표시, 경고 취소, 내보내기·복귀)을 가집니다. 그룹리더가 연락이 닿지 않을 때만 씁니다.
- 처음 만든 계정(초기 설정 계정)이 자동으로 총괄관리자가 됩니다. 총괄관리자는 최소 한 명이 있어야 하고, 두 명 이상 두기를 권합니다.
- **담당 영역**: 총괄관리자는 운영진마다 맡을 영역을 고를 수 있습니다. 영역은 회원·가입 / 그룹·성과 / 정기모임·소통 / 커뮤니티 / KPI·데이터 다섯 가지입니다. 정하지 않으면 모든 영역을 맡습니다. 영역을 정하면 그 밖의 메뉴는 왼쪽에서 사라지고, 주소로 들어와도 처리가 막힙니다(서버에서 막습니다).

## 2. 매일 할 일: 현황과 받은 일

**현황** 첫 줄의 "오늘 처리할 일"이 받은 일 7가지의 합계입니다. 기한이 지난 건은 빨간 테두리와 "기한 지남"으로 표시됩니다.

| 받은 일 | 기한 | 이렇게 처리합니다 |
|---|---|---|
| 가입 신청 | 3일 | 지원서를 읽고 승인하면 초대 코드와 보낼 안내문이 뜹니다. **안내문 복사**로 이메일이나 카톡으로 보냅니다. 신청서의 '먼저 해 보고 싶은 것'(정기모임·학습그룹·도전그룹)을 보고 첫 정기모임 안내를 함께 보내면 좋습니다. |
| 그룹리더 신청 | 5일 | 그룹 종류·주제·운영 계획·경험·시간과 함께 정기모임 출석, 그룹 모임 출석, 도전 기록, 완주 수가 보입니다. 승인하면 그 회원은 언제든 그룹을 만들 수 있습니다. 반려할 때는 다시 신청할 때 보완할 점을 적어 주세요. |
| 매출 확인 | 7일 | 도전그룹이 기록한 매출을 증빙과 맞춰 봅니다. 그룹 밖 고객의 결제인지, 돈이 오간 흔적이 있는지 확인하고 **확인**을 누르면 그 그룹의 활동 중인 그룹원 모두에게 첫 매출 배지가 나갑니다(이미 받은 사람 제외). |
| 발표 신청 | 일정 3일 전 | 정기모임 발제와 성과발표회 그룹 발표가 일정별로 모입니다. **확정**하면 회원에게 보이고, 발표가 끝나면 **발표함**을 눌러 포인트(발제 30점, 성과발표 50점)를 줍니다. |
| 페이퍼 검토 | 5일 | 수익 보장 표현, 다른 사람의 개인정보, 성과 기록과 어긋난 숫자, 안 된 것을 숨겼는지 봅니다. |
| 승급 심사 | 7일 | 기록상 조건 충족 여부가 표시됩니다. 보류·반려에는 사유를 꼭 적습니다. |
| 이의·신고 | 7일 | **그룹 퇴출 이의**는 그룹 상세에서 출석 기록과 경고 사유를 보고 그룹리더와 이야기한 뒤 결정합니다. 다시 받아야 하면 그룹 상세의 그룹원 표에서 **복귀**를 누릅니다(이전 경고는 모두 취소). 게시물 신고는 커뮤니티 관리에서 처리합니다. |

현황 아래쪽에는 다음이 있습니다.

- **핵심 지표**: 최근 30일 그룹 모임에 나온 회원(북극성 지표), 최근 7일 접속 회원, 모집·진행 중인 그룹(학습·도전·그룹리더 수), 최근 30일 그룹 출석률, 첫 매출 회원과 그룹 완주, 최근 30일 출석 경고와 퇴출.
- **주의가 필요한 그룹**: 아래 상황을 자동으로 찾아 보여 줍니다.
  - 진행 중인데 2주 넘게 모임도 일정도 없는 그룹 (모임 멈춤)
  - 출석을 받지 않고 지나간 모임이 있는 그룹 (출석 미확인)
  - 최근 마감 모임 3번의 출석률이 60% 미만인 그룹 (출석 저조, 40% 미만이면 위험)
  - 퇴출 기준에 닿았는데 그룹리더가 아직 결정하지 않은 그룹원 (퇴출 기준)
  - 모집을 연 지 2주가 지났는데 그룹원이 1명뿐인 그룹 (모집 부진)
  - 정한 기간이 지났는데 진행 중인 그룹 (기간 지남)
- **회원 흐름**: 가입 신청 → 계정 생성 → 오리엔테이션 → 그룹 참여 → 그룹 모임 출석 → 그룹 완주 → 성과 기록.
- **최근 8주**: 가입 신청, 새 계정, 마감한 그룹 모임, 도전 기록의 주간 추이.
- **다가오는 정기모임·일정**: 신청 인원과 발표 신청 수.

## 2-1. KPI 지표

**분석 → KPI 지표**의 탭은 요약 / 방문·유입 / 콘텐츠 / 회원 / 그룹·출석 / 커뮤니티입니다. 그룹·출석 탭에서는 새로 만든 그룹(학습·도전), 회원 그룹 참여율, 그룹 모임 출석률, 출석 경고와 퇴출, 중도 이탈률, 정기모임·일정 참석률, 그룹별 출석률·경고·도전 기록·성과·목표 진행을 봅니다. 각 숫자의 정의는 [KPI-정의.md](KPI-정의.md)에 있습니다.

## 3. 사람

**회원 상세**에서 볼 수 있는 것:
- 참여한 그룹별 역할, 출석률(그룹 기준과 비교), 출석·지각·결석·공결, 경고, 도전 기록·성과 기록 수
- **그룹리더**: 승인 여부와 신청 이력. **그룹리더 자격 주기 / 해제** 버튼으로 신청 없이 바로 처리합니다. 이끄는 그룹이 진행 중이면 해제할 수 없으니 먼저 리더를 바꾸거나 그룹을 마칩니다.
- 다음 등급까지 남은 조건, 포인트 내역, 등급·배지 이력(배지 회수), 기본 정보, 자기 자산 진단, 가입 신청서, 동의 기록, 일정 참석
- **내부 메모**: 운영진만 보는 메모
- **정착 단계**: 일곱 단계 중 어디까지 왔는지, 단체카톡방 참여 상태, 지금까지 보낸 안내. **다음 단계 안내 보내기**와 **단체카톡방 확인 / 나감으로 표시** 버튼이 있습니다.

### 3-1. 신규 회원 정착

**사람 → 신규 회원 정착**은 새로 가입한 회원이 첫 그룹 활동까지 어디쯤 왔는지 보는 화면입니다. 단계는 아래 순서입니다.

1. 오리엔테이션 → 2. 단체카톡방 → 3. 자기 자산 진단 → 4. 정기모임 참석 → 5. 그룹 참여 → 6. 그룹 모임 출석 → 7. 첫 도전 기록

| 상태 | 뜻 |
|---|---|
| 막 가입 | 가입한 지 3일 이내 |
| 진행 중 | 단계가 남았지만 최근에 접속함 |
| 멈춤 | 단계가 남았고, 멈춤 기준(기본 7일)보다 오래 접속하지 않음 |
| 정착 완료 | 일곱 단계를 모두 마침 |

- 위쪽 숫자: 기간 안 새 회원, 정착 완료, 멈춘 회원, 가장 많이 멈춘 단계. 정착 단계 막대로 어디서 가장 많이 빠지는지 봅니다.
- **다음 단계별로 안내하기**: 같은 단계 앞에 있는 회원에게 그 단계에 맞는 알림을 한 번에 보냅니다. 알림을 누르면 해당 화면(오리엔테이션, 단체카톡방 안내, 자기 자산 진단, 정기모임, 그룹 목록, 내 그룹)이 열립니다.
- 회원 표에서 골라 **다음 단계 안내**를 보낼 수도 있습니다. 덧붙일 말을 적으면 알림 끝에 붙습니다. 같은 회원에게는 정한 간격(기본 3일) 안에 다시 보내지 않고, 굳이 보낼 때는 한 번 더 확인합니다.
- **초대 코드를 받고 아직 가입하지 않은 분**: 승인 후 3일이 지나면 '다시 연락' 표시가 붙습니다. **안내문 복사**로 초대 코드 안내문을 다시 보냅니다.
- 안내는 회원 공간 알림으로만 갑니다. 이메일·문자는 보내지 않습니다.

## 4. 그룹

**그룹 현황**은 그룹이 멈추지 않고 모이고 있는지 보는 화면입니다. 진행 중·모집 중·끝남으로 나누고, 학습·도전그룹으로 거를 수 있습니다.

| 표시 | 뜻 |
|---|---|
| ● 순조 | 최근 출석률 60% 이상, 경고 없음, 모임이 이어지고 있음 |
| ▲ 주의 | 최근 출석률 60% 미만, 취소되지 않은 경고가 있음, 또는 10일 넘게 모임 없이 일정도 없음 |
| ■ 위험 | 최근 출석률 40% 미만, 또는 3주 넘게 모임도 일정도 없음 |

그룹을 누르면 모임별 출석률 막대, 그룹원별 출석·경고·기록, 모임 목록, 경고 기록, 성과 기록(여기서도 매출 확인 가능), 최근 도전 기록, 출석 규칙, 마일스톤, 처리 이력, 내부 메모가 한 화면에 나옵니다.

**운영진 조치**(진행으로·중단·종료·재개·다시 열기, 그룹리더 교체)는 사유를 받아 그룹원 모두에게 알림으로 보냅니다. 그룹리더와 먼저 이야기한 뒤에 처리합니다. 종료하면 열려 있던 출석은 마감됩니다.

**시즌**은 신규 회원 모집과 성과발표회 주기를 맞추는 달력입니다. 상태를 **신규 회원 모집**으로 두면 홈페이지 첫 화면과 가입 신청 페이지에 모집 안내가 뜹니다. 그룹은 시즌과 관계없이 언제든 만들 수 있습니다.

## 5. 소통

- **정기모임·일정**: 유형(정기모임·성과발표회·세미나·워크숍·오피스아워·네트워킹), 방식(오프라인·온라인·온·오프라인), 장소, 온라인 참여 링크(신청한 회원에게만 보임), 다룰 주제(사업 아이디어·시장 분석·트렌드·AI 활용·사이드프로젝트·그룹 소식)를 정해 만듭니다. 상세 화면에 출석 코드가 크게 나오고, 코드를 넣지 못한 사람은 신청자 목록에서 직접 **출석 처리**합니다. 같은 화면에서 발표 신청을 확정합니다.
- **단체 알림**: 모든 회원, 특정 등급 이상, 그룹에 참여 중인 회원, 아직 그룹이 없는 회원, 특정 그룹의 그룹원, 그룹리더 전체, 운영진 중에서 고릅니다. 정기모임 전에는 '아직 그룹이 없는 회원'에게 새 그룹 소개를 보내면 좋습니다.
- **단체 알림**의 받는 사람에 v2.1부터 '단체카톡방에 아직 없는 회원', '가입 30일 이내 회원', '오리엔테이션을 안 마친 회원'이 추가되었습니다.
- **단체카톡방**: 세 개의 탭으로 나뉩니다.
  - **참여 현황**: 참여율과 상태별 회원 수. 상태는 아직 안 들어옴 → 링크만 누름(회원이 링크를 누름) → 참여했다고 표시(회원이 '참여했어요'를 누름) → 운영진 확인 순서이고, 나간 회원은 나감으로 둡니다. 카카오톡 대화방 참여자 목록과 닉네임을 맞춰 보고 **확인**을 누르세요. 사이드 메뉴 숫자는 확인을 기다리는 회원 수입니다. 오리엔테이션을 마쳤지만 대화방에 없는 회원에게는 **참여 안내**를 보냅니다(같은 회원에게 3일에 한 번).
  - **공지 만들기**: 새 회원 소개, 다가오는 정기모임, 모집 중인 그룹, 이번 주 그룹 소식 문안을 기록에서 바로 만들어 줍니다. 문안을 다듬어 **복사**한 뒤 카카오톡에 붙여 넣고, **대화방에 올렸어요**를 눌러 기록합니다. 새 회원 소개를 기록하면 소개한 회원은 다음 목록에서 빠집니다. 이 화면에서 카카오톡으로 바로 보내지는 않습니다.
  - **설정**(총괄관리자만): 안내 켜기·끄기, 대화방 이름, 오픈채팅 주소(https), 참여코드, 회원에게 보일 한마디, 신규 회원 정착 기준(정착 기간·멈춤 기준·같은 안내 간격). 저장할 때 이유를 남깁니다. 주소와 참여코드는 로그인한 회원에게만 보입니다.
- **커뮤니티 관리**: 신고된 글을 확인하고 숨기거나 기각합니다. 그룹 모집을 핑계로 한 광고, 수익 보장 표현은 숨깁니다.

## 6. 설정

- **규칙 설정**
  - **그룹 규칙**: 기본 정원, 최대 정원, 그룹리더 한 명이 동시에 이끄는 그룹 수, 회원 한 명이 동시에 참여하는 그룹 수, 그룹 참여·그룹리더 신청 가능 등급
  - **출석 규칙 기본값**: 최소 출석률, 출석률 확인 시작, 지각 기준과 환산, 연속 결석 경고, 출석률 경고, 퇴출 기준, 자동 퇴출, 공결 인정과 횟수, 출석 코드 입력 시작. 새로 만드는 그룹에만 쓰이고, 이미 있는 그룹은 그룹리더가 정한 값을 그대로 씁니다.
  - 승급 조건, 열람 권한, 활동 포인트
  - 저장할 때 바꾸는 이유를 묻고, 변경 이력에 남습니다. 바꾼 내용은 정기모임이나 공지 게시판에서 알려 주세요.
- **감사 로그**: 누가 언제 무엇을 처리했는지 남습니다. 행동 종류로 그룹·모임·출석·그룹리더·매출 확인·발표 등을 골라 볼 수 있습니다.
- **데이터·백업**: 그룹, 그룹원, 그룹 모임, 모임 출석, 성과 기록 CSV와 전체 백업(JSON). 시즌이 끝날 때마다 백업을 한 번씩 받아 보관하세요.

## 6-1. 총괄 관리 (총괄관리자)

왼쪽 메뉴 아래쪽 **총괄 관리** 묶음입니다. 운영진·권한, 사이트 운영, 규칙 설정, 감사 로그, 데이터·백업은 운영진도 볼 수 있지만 바꾸는 것은 총괄관리자만 합니다. 총괄 현황과 보안·접속은 총괄관리자에게만 보입니다.

- **총괄 현황**: 맨 위 **총괄관리자 점검표**에서 손볼 것을 먼저 봅니다. 점검하는 것은 아래와 같습니다.
  - 총괄관리자가 두 명 이상인지
  - 30일 안에 전체 백업을 받았는지
  - 처리 기한이 지난 받은 일이 있는지
  - 90일 넘게 접속하지 않은 운영진이 있는지
  - 운영 주체 정보가 비어 있지 않은지
  - 단체카톡방 안내가 켜져 있는지
  - 회원 신청 상태
  - 신청서 자동 파기 현황

  그 아래에는 회원과 커뮤니티 숫자, 받은 일별 대기·기한 지남·30일 처리 건수·평균 처리 일수, 운영진별 7일·30일 처리량과 담당 영역, 시스템 상태, 최근 바뀐 규칙·권한이 나옵니다.
- **운영진·권한**: 운영진을 추가·해제하고, 총괄관리자로 지정·해제하고, **담당 영역**을 고릅니다. 마지막 처리 시각, 마지막 로그인, 로그인한 기기 수도 같이 봅니다.
- **사이트 운영**
  - **회원 신청**을 '잠시 닫기'로 바꾸면 홈페이지 신청서가 잠기고, 적어 둔 안내가 대신 보입니다. 서버도 신청을 받지 않습니다.
  - **공지 띠**는 맨 위에 한 줄로 뜨는 안내입니다. 문구, 누르면 열 곳, 끝나는 날을 정하고, 회원 공간에만 띄울지 홈페이지에도 띄울지 고릅니다. 끝나는 날이 지나면 저절로 사라집니다.
  - 회원이 공지 띠를 닫으면 문구를 바꿀 때까지 다시 보이지 않습니다.
- **보안·접속**
  - 최근 24시간 로그인 실패를 입력한 이메일별·IP별로 보여 줍니다. 운영진 계정으로 실패가 있으면 빨갛게 알립니다.
  - 운영진이 로그인한 기기(예: Chrome · Windows)를 보여 줍니다. 모르는 기기는 **로그아웃**으로 끊고, 계정이 걱정되면 **모든 기기 로그아웃** 뒤 비밀번호를 바꿉니다.
  - 지금 쓰고 있는 기기는 여기서 끊을 수 없습니다.
  - 같은 이메일로 15분 안에 10번, 같은 IP로 30번 실패하면 잠시 로그인이 막힙니다.
- **데이터·백업 → 데이터 정리**: 만료된 로그인 기록, 읽은 지 180일 지난 알림, 하루 지난 로그인 실패 기록을 지웁니다. 지울 때 이유를 남기고, 지운 기록은 되돌릴 수 없습니다. 마지막 전체 백업 날짜도 여기서 확인합니다.

## 7. 운영 리듬

| 언제 | 할 일 |
|---|---|
| 매일 20분 | 현황 → 받은 일 비우기 |

- 화면: `public/app/views/group.js`(회원의 그룹 공간), `public/app/views/admin/`(`home.js`, `inbox.js`, `people.js`, `groups.js`, `comms.js`, `system.js`, `kpi.js`, 공통 `shared.js`).
- 점검: `npm test`, `node tests/admin-flow.js`, `node tests/site-flow.js`, `node tests/screenshots.js [--mobile]`.
